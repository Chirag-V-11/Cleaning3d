# Orellana’s Cleaning LLC — Dallas, TX

A modern web experience for **Orellana’s Cleaning LLC** featuring a single 3D object with smooth scroll animation, a strict 3-color minimalist palette, and dedicated separate Booking and Contact pages.

---

## 🎨 Strict 3-Color Design System
Every element, text, border, button, and 3D material uses strictly 3 colors (and their alpha transparencies):
1. **Obsidian Deep Canvas:** `#0D1117`
2. **Crisp Pure White:** `#FFFFFF`
3. **Electric Clean Mint:** `#00E599`

## 🚀 Running the Project

```bash
# Install dependencies (already completed)
pnpm install

# Start local development server
pnpm run dev

# Build for production
pnpm run build

# Preview production build
pnpm run preview
```
